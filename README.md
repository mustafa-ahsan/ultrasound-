# 🩺 Ultrasound High-Resolution Detail Enhancer (مُعالج السونار عالي الدقة)

أداة برمجية تفاعلية مبنية بلغة Python مخصصة لطلاب ومختصي تقنيات الأشعة والسونار. 
تقوم هذه الأداة بمعالجة صور السونار (Ultrasound) الباهتة وتحويلها إلى صور عالية الوضوح مع إبراز الحواف المخفية وتلوينها حرارياً لتسهيل التشخيص وفهم التشريح السوناري (Sono-Anatomy).

## ✨ المميزات (Features)
* **إبراز التفاصيل (CLAHE):** توضيح الأنسجة الداخلية والتباين الموضعي دون تشويه الصورة.
* **حدة الحواف (Sharpness):** جعل حدود الأعضاء (مثل الكبد، الكلى، أو العضلات) قاطعة وواضحة جداً.
* **التلوين الطبي (Pseudocoloring):** تحويل التدرج الرصاصي إلى ثيمات ملونة (مثل ثيم العظام، والحراري) لتمييز السوائل عن الأنسجة الصلبة بسهولة.
* **واجهة تفاعلية:** تحكم كامل بقوة التباين والحدة عبر أشرطة التمرير (Sliders) ورؤية النتائج لحظياً.
